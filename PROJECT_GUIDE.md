# Women Safety Device Using GPS and GSM

Major project documentation and supporting materials for a fingerprint-activated women safety device integrating GPS, GSM, Arduino UNO, buzzer, LCD, LEDs and power supply.

Project title: Integrating GPS and GSM Technologies for Enhanced Women's Safety: A Fingerprint-Activated Device Approach

This repository contains the project documentation, diagrams, reports, presentation, and supporting files.
